Security checklist

开户之后，先把这几件事做了

顺序很重要：先做安全设置，再入金。这几步加起来不到十分钟。

开启双重验证（2FA）

优先使用验证器 App（如 Google Authenticator、Authy），不要把资金安全押在短信验证码上。

设置提币地址白名单

开启后只能提币到你预先登记的地址。即使账号被攻破，资产也转不走。

开启反钓鱼码

设置后，交易所发给你的每一封邮件都会带上这个专属码 —— 没有这个码的邮件就是钓鱼邮件。

给 TradeMind 用的 API Key 只勾「读取」

TradeMind 只需要读取历史成交记录，所以创建密钥时只勾选「读取」，不要勾「交易」和「提币」； 同时绑定 IP 白名单。程序在绑定密钥后会自动探测权限，一旦发现多给了权限会在界面上警告你。

别把全部资产长期放在交易所

交易所存在对手方风险（宕机、提币暂停、极端行情下的强平）。交易用的保证金之外，大额资产建议用硬件钱包自托管。

Risk warning

风险提示

合约与杠杆交易的风险极高。在杠杆作用下，行情的小幅波动就足以吃掉全部本金； 公开统计与交易所自己的数据都反复表明，绝大多数参与者在较长周期里是亏损的。

本项目不提供投资建议、不代客理财、不承诺任何收益，也不对使用者的交易结果承担任何责任。
